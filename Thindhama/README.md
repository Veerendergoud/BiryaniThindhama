# Thindhama — 3D Restaurant Website

A custom restaurant landing page built with:
- HTML5
- CSS3
- Vanilla JavaScript
- CSS 3D transforms / perspective
- Scroll reveal animations
- Interactive menu filters
- Mobile navigation
- Add-to-feast micro interaction
- Online food photography
- Google Fonts (Cinzel + DM Sans)

## Run locally
Open `index.html` in a browser.

For VS Code, Live Server is recommended.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Make sure `index.html` is in the repository root.
4. GitHub → Settings → Pages.
5. Select "Deploy from a branch".
6. Select `main` and `/root`.
7. Save.

## Customize
- Replace the brand mark in `index.html` with your own `BackgroundFood.png` if desired.
- Change menu prices/text in `index.html`.
- Replace the remote food images with your own optimized images for a fully self-contained deployment.
- Update the Google Maps and phone links before publishing.

## Image note
This demo references online image URLs. Check the current license/usage terms of each source before using the site commercially. Unsplash provides a large food-photo library and identifies individual photos with their license information.
